# Roadmap

## Phase 0: MVP Scaffold

- Local private git repository.
- FastAPI backend with run lifecycle APIs.
- Next.js research workbench.
- OpenAlex search and Crossref citation verification.
- Evidence ledger, hypothesis debate, experiment plan, report export.
- Docker Compose for local server deployment.

## Phase 1: Bailian/Qwen Hardening

- Add prompt templates for every agent.
- Persist Qwen prompt/response logs for contest screenshots.
- Add model routing for qwen-max/qwen-plus/qwen-turbo.
- Add JSON schema retry and validation.

## Phase 2: Literature and Browser Automation

- Add Semantic Scholar and arXiv tools.
- Browser-worker now supports Playwright screenshots and first-pass PDF download; next step is agentic navigation.
- Save browser trace metadata for demo video.
- Support user-uploaded PDF parsing and page-level evidence.

## Phase 3: Scientific Data Layer

- Add Materials Project adapter.
- Add Matbench sample task runner.
- Add dataset profile cards and simple baseline experiments.
- Generate quantitative result cards for the `Results` field.

## Phase 4: Submission Package

- Prepare PDF technical proposal under 20 pages.
- Record a 10-minute demo video.
- Add screenshots showing Bailian API usage.
- Freeze a high-quality demo run and report.

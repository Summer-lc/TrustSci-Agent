# Next.js Frontend

The frontend is a Next.js App Router application under `frontend/`.

## Entry Points

- `app/page.tsx`: renders the workbench shell.
- `components/workbench/Workbench.tsx`: owns client-side state, polling, run creation, browser capture, and initial data loading.
- `lib/api.ts`: typed API client for the FastAPI backend.

## Workbench Components

- `ResearchConsole`: research task input and run controls.
- `RunHistory`: in-memory backend run list.
- `StatusStrip`: model/data/run status.
- `RunTimeline`: agent execution steps.
- `EvidenceBoard`: evidence ledger preview.
- `CitationVerifier`: paper and DOI verification status.
- `ScientificDataPanel`: Matbench/Materials Project/local data profile and baseline result.
- `HypothesisArena`: candidate hypotheses and critic scores.
- `ExperimentPlanPanel`: datasets, baselines, metrics, and target summary.
- `BrowserCapturePanel`: backend-proxied browser-worker capture.
- `ReportViewer`: final report preview and export links.

## Development

```bash
cd frontend
npm install
NEXT_PUBLIC_API_BASE=http://localhost:8011 npm run dev -- -p 3001
```

For Docker/WSL development use:

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```

`frontend/next-env.d.ts` is generated by Next.js and intentionally ignored to avoid dev/build path churn across machines.

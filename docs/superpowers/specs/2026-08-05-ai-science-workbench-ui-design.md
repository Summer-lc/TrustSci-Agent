# AI for Science 科研工作台界面优化设计

## 目标

在不改变现有科研流程、接口和数据模型的前提下，把当前三栏工作台从“功能堆叠”调整为“任务—证据—上下文”结构。用户应能快速发起研究、判断当前进度、浏览证据，并在不离开页面的情况下核查论文原文与运行状态。

## 设计参考

- Elicit：问题优先、结构化论文列表和证据对比，适合高密度文献筛选。
- FutureHouse：明确展示代理执行阶段和来源评估过程，适合建立可信感。
- Consensus：答案、引用和 PDF 原文保持紧密关联，适合快速核验。

本项目吸收这些信息架构原则，不复制其品牌、文案或具体布局。

## 信息架构

### 左栏：任务控制台

- 页面打开后直接进入工作台；经典与地震版本在左上角切换，不再增加重复入口页。
- 始终显示版本、科研模式、研究领域和科研问题。
- 最大论文数、运行模式和检索源归入“研究设置”，默认折叠。
- “启动研究”作为唯一主操作；刷新降为次操作。
- 执行日志和历史任务保持可用，但视觉权重低于任务输入。

### 中栏：当前研究阶段

- 顶部用紧凑标题区显示研究问题、运行状态和当前阶段。
- 阶段导航保持完整，但弱化卡片感，形成连续科研流水线。
- 文献阶段使用证据矩阵代替大段卡片：突出题名、来源、年份、核验状态、报告资格和相关性。
- 摘要、链接和更深层信息移到右侧上下文面板，减少重复。

### 右栏：上下文检查器

- 提供“文献 / 证据 / 运行”三个标签页。
- 文献页保留 PDF 原文阅读与手动重试能力。
- 证据页显示当前论文的核验、报告资格、分类和来源信息。
- 运行页显示任务状态、当前阶段和最近步骤，帮助用户理解系统正在做什么。

## 视觉原则

- 使用低饱和蓝灰背景、深海军蓝文本与青绿色可信状态，减少高对比边框。
- 依赖留白、字号和浅色表面建立层级，避免每个区域都像独立卡片。
- 表格行使用清晰的选中态和悬停态；状态使用文字与颜色共同表达。
- 桌面端维持三栏，窄屏端继续使用分区切换并将右栏命名为“上下文”。

## 可访问性与响应式

- 标签页提供 `role="tablist"`、`role="tab"`、`aria-selected`。
- 证据矩阵保留明确按钮焦点与选中状态，不仅依赖颜色。
- 小屏隐藏矩阵表头，将每行重新排列为可扫读的卡片行。

## 非目标

- 不改变论文检索、核验、Baseline、实验和报告生成逻辑。
- 不增加新的后端接口。
- 不自动抓取受人机验证保护的论文页面。
- 不在本次改动中引入新的 UI 框架或设计系统依赖。

## 验收标准

1. 打开页面直接进入工作台，并可在左上角切换版本。
2. 高级研究设置默认折叠，启动操作保持显眼。
3. 文献候选以证据矩阵呈现，选择论文会打开右侧文献页。
4. 右侧可在文献、证据、运行三个上下文间切换。
5. 桌面和移动布局均无文字截断、横向溢出或不可操作控件。
6. 原有前端测试通过，新增结构测试通过，生产构建成功。

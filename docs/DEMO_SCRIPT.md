# 10-Minute Demo Script

1. Open the workbench and enter an energy-materials research question.
2. Start the workflow and show the agent timeline.
3. Show papers collected from OpenAlex.
4. Show Crossref verification status and audit details.
5. Show Evidence Board entries bound to source papers.
6. Show three candidate hypotheses in Hypothesis Arena.
7. Explain Critic Agent scoring and revision advice.
8. Show the experiment plan with datasets, baselines, metrics, and failure modes.
9. Show the final contest-format report and citation audit log.
10. Close with scoring alignment: scientific value, technical depth, application potential, reproducibility.
